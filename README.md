# Partnership Income & Expense Calculator (آسان پارٹنرشپ کیلکولیٹر)

A lightweight, professional, single-page Partnership Accounting & Employee Settlement Calculator designed for transparent profit/loss sharing and employee advance/salary deduction tracking.

## Features
- **Accurate Ownership Share Allocation**: Uses exact fractional shares (Mohsan 1/3, Muzzmal 2/3).
- **Multi-Employee Advance & Settlement**: Track advances given to employees (Ayaz, Ashraf, Javed, and custom staff), expenses made, remaining cash, and automatic salary deductions.
- **Out-of-Pocket Tracking**: Separately accounts for personal funds invested by partners vs. business cash collected.
- **Real-Time Settlement Directive**: Instantly calculates who owes whom without complicated ledgers.
- **Offline & Local Storage**: No database or backend required. Runs directly in any web browser and remembers inputs.

## Live Deployment (GitHub Pages)
This project is ready to run directly via GitHub Pages:
1. Go to repository **Settings** > **Pages**.
2. Under **Branch**, select `main` and root `/`.
3. Click **Save**. Your site will be live at:
   `https://<username>.github.io/<repo-name>/`
